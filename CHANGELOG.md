## [0.1.0] - 2026-07-29

### Added

- Initial public release of DynamicsMetrics.jl.
- Unified interface for evaluating dynamical-system prediction metrics.
- Metric objects and structured result types.
- Access to metric values, parameters, and metadata.
- Extensible API for defining custom metrics.
- Reproducibility metadata support.
- Automated package tests and example execution.
- Continuous integration for Julia 1.10 and current Julia releases.
- Documenter.jl-based online documentation.
- Codecov coverage reporting.
- General Registry compatibility.
